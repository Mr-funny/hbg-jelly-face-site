# 交付前检查清单

## 图片

- [ ] 所有表情都是同一个人，发型、衣服、头部位置和大小基本一致。换表情时头不应该"跳"一下。
- [ ] 每张图都有透明背景（`prepare_faces.py` 没有报警告）。
- [ ] `img/faces.json` 里 `pain` 和 `fun` 各至少一张；只有一张图时两个列表都是空的也可以。
- [ ] 用的是真人照片时，确认是用户本人或已获授权。

## 页面

- [ ] 用本地服务器打开（不是 `file://`），控制台没有报错。
- [ ] 抓住脸往外拽能拉长，松手会回弹并抖动；按下和松手都会换表情。
- [ ] 点击空白处、选中文字时不会误触发拖拽。
- [ ] 手机宽度（375px）下头像在上、文字在下，拖拽脸时页面不会跟着滚动。
- [ ] 游戏名、标语和规则符合用户要求；换了角色的话，页面上的文字不能再提旧角色。
- [ ] 不要用真实媒体的 logo 或"被某某报道"之类的字样，除非用户真的被报道过。

## 密钥

- [ ] `grep -rn "<密钥前几位>" <站点目录>` 没有结果。
- [ ] `.env` 和 `raw/` 在 `.gitignore` 里。
- [ ] 回复用户时没有复述密钥。

## 发布

- [ ] `deploy_pages.sh` 的扫描通过了。
- [ ] 等 1–2 分钟后打开 `https://<用户名>.github.io/<仓库名>/` 确认能访问，并实际拖一下。
