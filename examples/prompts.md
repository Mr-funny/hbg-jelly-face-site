# 提示词示例

## 把自己做成游戏

```text
使用 $hbg-jelly-face-site，用 ~/Desktop/me.jpg（我本人）生成全套表情和伤势，
先给我看预览图，确认后发布到 GitHub Pages，仓库叫 punch-me。
```

## 只换皮不换人

```text
使用 $hbg-jelly-face-site 用示例角色建站，游戏名改成"周一解压馆"，
标语改成"把周一打成猪头"，主色换成 #2563eb。
```

## 一句话虚构角色

```text
使用 $hbg-jelly-face-site 生成一个虚构角色：留着八字胡、戴厨师帽的意大利厨师。
只要捏脸表情和拳击反应，不要伤势。
```

## 只补几张图

```text
使用 $hbg-jelly-face-site 在 my-game 里只重新生成 hit_left 和 dmg2_hit_right，
其他图保持不变。
```

## 调难度

```text
使用 $hbg-jelly-face-site 把拳击挑战改成 20 秒，
伤势门槛改成 30 / 80 / 150 / 250，连击窗口放宽到 800ms。
```
